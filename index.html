Stream Processing

PySpark — The Enrichment Engine

PySpark Structured Streaming reads raw orders from Kafka in micro-batches, adds computed fields, then writes enriched events to a second Kafka topic for Pinot to consume.

1
Read from Kafka
Uses spark.readStream.format("kafka") to subscribe to raw-food-orders. Kafka connector JAR is automatically downloaded via Maven at startup.
spark-sql-kafka-0-10_2.12:3.3.2
2
Parse JSON Schema
Kafka messages arrive as raw bytes. from_json(col("value").cast("string"), schema) converts the binary payload into a typed DataFrame with 17 columns.
StructType with 17 fields
3
Compute Enrichment Fields
5 new columns are added using Spark SQL functions. No UDFs needed — all vectorized operations on the DataFrame.
hour_of_day — from epoch ms is_peak_hour — lunch/dinner rush order_value_category — Budget/Mid/Premium price_per_item — price ÷ quantity is_high_value — price ≥ ₹1000
4
Write to Processed Topic
Enriched DataFrame serialized back to JSON via to_json(struct(...)) and written to processed-food-orders. Checkpoint stored in /tmp/spark-checkpoint for exactly-once semantics.
append mode · continuous query
PySpark · spark_streaming.py — Enrichment Logic 
# ── Enrich with computed fields ──────────────────────────────
enriched = (
    parsed
    # Hour of the day (0-23) derived from epoch ms timestamp
    .withColumn("hour_of_day", hour(from_unixtime(col("timestamp") / 1000)))

    # Peak hours: lunch (12-14) and dinner (19-22)
    .withColumn("is_peak_hour",
        when(col("hour_of_day").between(12, 14) | col("hour_of_day").between(19, 22),
             lit(1)).otherwise(lit(0)))

    # Bucket orders by price range
    .withColumn("order_value_category",
        when(col("price") < 200, lit("Budget"))
        .when(col("price") < 600, lit("Mid-Range"))
        .otherwise(lit("Premium")))
)

Analytics

10 Queries, All on Live Data

Every query runs against the live streaming dataset. Run them at localhost:9000 → Query Console. Results refresh in real-time as new orders arrive.

📊 Total Orders & Revenue 
SELECT COUNT(*) AS total_orders,
       ROUND(SUM(price), 2) AS total_revenue
FROM food_orders
🏙️ Revenue by City 
SELECT city, COUNT(*) AS orders,
       ROUND(SUM(price), 2) AS revenue
FROM food_orders
GROUP BY city ORDER BY revenue DESC
🍜 Top Cuisines 
SELECT cuisine, COUNT(*) AS orders,
       ROUND(AVG(price), 2) AS avg_price
FROM food_orders
GROUP BY cuisine ORDER BY orders DESC
🕐 Peak vs Off-Peak Hours 
SELECT is_peak_hour, COUNT(*) AS orders,
       ROUND(AVG(price), 2) AS avg_price,
       ROUND(AVG(delivery_time_mins), 1) AS avg_eta
FROM food_orders GROUP BY is_peak_hour
💳 Payment Method Split 
SELECT payment_method,
       COUNT(*) AS orders,
       ROUND(SUM(price), 2) AS total_revenue
FROM food_orders
GROUP BY payment_method ORDER BY orders DESC
💰 Order Value Segments 
SELECT order_value_category,
       COUNT(*) AS orders,
       ROUND(AVG(price), 2) AS avg_price
FROM food_orders
GROUP BY order_value_category
⭐ Top Restaurants by Rating 
SELECT restaurant_name,
       ROUND(AVG(rating), 2) AS avg_rating,
       COUNT(*) AS orders
FROM food_orders WHERE status = 'delivered'
GROUP BY restaurant_name ORDER BY avg_rating DESC
📅 Hourly Order Volume 
SELECT hour_of_day, COUNT(*) AS orders
FROM food_orders
GROUP BY hour_of_day
ORDER BY hour_of_day
